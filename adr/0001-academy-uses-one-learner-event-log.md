# Academy uses one learner event log

Reconsidered 18 September 2026. Academy and Reader should share learning evidence and item identity rather than duplicate progress flags. This does not make Yomu the owner of external review schedules: the learner's chosen destination retains its card IDs, due work and review history. Event-log storage is an implementation choice to verify, not a reason to force every provider through a Yomu scheduler. See ADR-0016.
