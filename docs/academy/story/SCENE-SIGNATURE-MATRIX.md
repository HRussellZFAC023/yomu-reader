# Scene signature matrix

## Decision

The canonical story already contains unusually strong object and stage direction. This is not a request to decorate 105 scenes. It is a binding plan for one memorable detail per scene, keeping 81 as authored, refining 24, and inventing none from a blank page.

**Census:** 48 canonical `*.v2.json` packages, 105 unique scene IDs, 290 authored `stage` nodes, and zero scenes without a `stage` node. Chapter 1 owns 11 scenes; Chapters 2–48 own two each. Counts in this matrix are mechanically re-checkable from `src/academy/content/story-sources/`.

| Verdict | Scenes | Meaning |
| --- | ---: | --- |
| Keep | 81 | The authored object/action is already specific enough. Implementation should bind it without adding a second flourish. |
| Refine | 24 | A good authored detail exists, but a one-time interaction, optional task-anchored talk, or restrained presentation binding gives it a clearer job. |
| Missing | 0 | No canonical scene needs a newly invented signature premise. |

## Inventory findings and implementation contract

- `docs/academy/story/PRESENTATION-BINDING.json` and `ASSET-INTEGRATION-MAP.json` cover Chapters 1–24 only. They provide useful SFX, ambience, background, and portrait decisions, but are not 48-chapter presentation authority yet.
- `src/academy/ui/story-screen.ts#renderMoment` exposes stable scene, node, and moment IDs. `src/academy/ui/vn-stage.ts` already owns `setDirection`, `setObject`, `setCast`, reduced-motion detection, pointer parallax, keyboard-safe action slots, and stage disposal. The story screen does not currently call `setObject`; that is the clean prop/hotspot seam.
- `src/academy/vn/performance-contract.ts` and `performance-engine.ts` already support one-shot entrances, expression/angle changes, camera moves, paper/ink reveals, pauses, music, SFX, and reduced-motion cuts. Do not add another animation engine.
- `src/academy/assets.ts` is the sole runtime art authority: 71 records (60 approved, 11 review-preview), comprising 23 character sprites, 4 protagonist portraits, 32 backgrounds, 4 event images, and 8 item images. `public/academy/art/ASSET-USAGE.json` reports 105 runtime files and 1,743 non-runtime review files. A file merely present under `public/academy/art/` is not reusable until registered.
- The runtime already binds `event.empty-microphone-rehearsal`, `event.withheld-panel-handoff`, and `event.atlas-finale-next-page` to eight canonical scenes. Every proposed new art ID below is **approval-dependent** and must enter the forthcoming approved-art JSON and `src/academy/assets.ts` before use. Name-only remains the fallback for unapproved likenesses.
- `src/academy/audio/sfx-catalog.ts` has 26 semantic cues: 19 mapped and 7 explicit gaps. Reuse only named mapped cues. `door.open`, `door.close`, `speaker.arrival`, and footsteps remain silence until approved/delivered; never substitute a UI confirmation sound for a physical door.
- One-time state uses a proposed non-canonical learner event `scene-signature-triggered { sceneId, signatureId, outcome }` in `src/academy/domain/learner-record.ts`. It may remember an inspection or optional-talk choice across devices, but it appends no canon, bond, lesson, relationship, unlock, or graduation progress. Replay shows the settled visual and an explicit “Inspect again” action; it never duplicates the first response.
- A hotspot is a real button in the VN object slot, at least 44 × 44 CSS px, reachable by Tab and activated by Enter, Space, click, or touch. It has a visible low-noise affordance (`Inspect`, `Open`, or a named object), an accessible name, and a nearby non-interactive fallback sentence. No pixel hunting.
- A **shared-universe** marker (`SU`) is allowed only on a real package/ledger callback. Every SU ID in this matrix resolves to `docs/academy/story/CALLBACK-LEDGER.md#plot-callbacks`; it changes the object's job at the cited lifecycle state and is not a recognition-only cameo.
- A **skin-deep** marker (`SD`) is an optional, deferrable talk that starts from the immediate Japanese task. Subtext may expose a preference, limit, or practical stake from `CAST-AND-CONSENT.md`; it may not force disclosure, invent harm, or make the “warm” answer mechanically superior. Every SD beat has a context-complete no-talk path and cites the matching per-character story dossier under `docs/academy/story/dossiers/`.
- The deterministic dossier gate parses matrix data rows and inspects the chosen-signature cell after stripping Markdown emphasis. A row is SD-bearing when that cell matches `(?:^|\+\s)SD (?<character>[A-Z][A-Za-z-]*) /`; this deliberately includes compound forms such as `Notebook hotspot + SD Sophie /` and `Door + SD Nanako /`. Each matched row requires exactly one backticked `Story dossier: docs/academy/story/dossiers/<character>.md` token, one backticked section heading after `§`, and one quoted concept after `—`. The filename must equal the normalized captured character name; the heading must exactly match a real Markdown heading in that file; after stripping inline Markdown and normalizing whitespace, the quoted concept must occur within that heading's section. The gate rejects discovery-only or callback-only provenance and expects exactly 10 matched rows.

### Compact notation

- `SRC/<id>#<node>` = exact file `src/academy/content/story-sources/<id>.v2.json` and exact node ID.
- `SS`, `VS`, `PC`, `LR`, `AS`, `SFX` = `src/academy/ui/story-screen.ts#renderMoment`, `src/academy/ui/vn-stage.ts`, `src/academy/vn/performance-contract.ts`, `src/academy/domain/learner-record.ts`, `src/academy/assets.ts`, and `src/academy/audio/sfx-catalog.ts`.
- `R` = reuse registered runtime art; `N[id]` = proposed approval-dependent runtime asset ID and file. `Text/CSS` means no raster dependency.
- `A0` = static/cut, descriptive text/alt, performance risk low. `A1` = one-shot up to 420 ms; reduced motion is the final static state; risk low. `A2` = persisted one-time hotspot with keyboard/touch semantics; reduced motion is a cut; risk low. `A3` = restrained depth, lighting, or weather change; reduced motion removes parallax/travel and uses one static plate; pause offscreen; risk medium. `A4` = optional SD talk; explicit Talk/Not now controls, no autoplay, captioned audio, no entrance motion under reduced motion; risk low.
- Each `U###` is an owner-sized unit: one scene binding plus its focused test. Verification syntax `DOM <signature>` means a deterministic test opens the exact scene, asserts `[data-scene-signature="<signature>"]`, triggers it where applicable, asserts one event/one response, then reopens and asserts the settled replay state.
