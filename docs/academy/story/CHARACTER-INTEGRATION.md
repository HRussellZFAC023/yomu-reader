# Character Integration Plan

**Purpose.** This is the authoring bridge between the 24 deep character dossiers (`scratchpad/academy/dossiers/*.md`) and the 48-chapter canon. Chapter authors pull the *specific* real details, beats, running jokes, and per-chapter learning function from here. Nothing in this document overrides `STORY-BIBLE.md`, `CONTENT-LINKAGE.md`, `CALLBACK-LEDGER.md`, `RELATIONSHIP-MATRIX.md`, or `CAST-AND-CONSENT.md`. Where those files fix a lead, a beat placement, a reservoir, a callback budget, or a consent boundary, this document only *enriches within* that frame.

**Canon order of precedence:** `SPINE.md` → `STORY-BIBLE.md` → arc matrix → this file. If any enrichment below appears to conflict with a higher document, the higher document wins and the conflict is logged in §6 (Owner decisions).

**Standing frame.** Everything opens under Rie's spoken AI-fiction disclaimer. First names only. Real texture is owner-authorized to make characters true; the only line is warmth — never fabricate anything that would embarrass or harm a real person. Two hard content rules from the arc matrix run through every chapter: (1) **nobody is ever the butt of a language-mistake joke** — gags are about cars, recorders, spreadsheets, scarves, karaoke, never about a particle; (2) **every comedy callback is suspended from the first boundary/refusal/apology beat** until the other person changes the action.

## 1. Per-chapter enrichment map

Each entry gives: **Lead(s) + supports** (fixed by bible/matrix), **Learning function + reservoir + activity** (fixed by CONTENT-LINKAGE), **Enrichment to fold in** (real details/beats/jokes, from the dossiers), and **Callbacks** (state + owner, from the ledger). Supports never exceed the one-lead / two-support / two-reactive-background cap; extra matrix beats route to class-thread or montage.
