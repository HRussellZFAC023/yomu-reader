# Grammar coverage

The Grammar card always stays visible after a check. A local match shows the
pattern and its target-owned level. Detection is deliberately narrow: a match
is a prompt to inspect the sentence, not a complete parse.

Every learning target now owns at least one source-checked local construction.
Japanese keeps its established 307-rule JLPT inventory. The other targets use
published levels only when the cited curriculum assigns one: CEFR for five
targets, the source's combined A1–A2 band for Turkish, and the HSK Standard
Course scale for Chinese. `Foundation` means only “this target's first
checked local rule”; it is not a proficiency level and is not equivalent across
languages.

Yomu bundles only the small detector patterns above. The linked sources define
the construction names, scopes, and any published levels; they are not copied
into the bundle. A broader unreviewed regex would create false grammar teaching,
so new coverage grows through checked examples and adversarial near-negatives.
