## Chrome, Edge, Brave, Vivaldi, Opera {#chrome}

[Add よむ from the Chrome Web Store](https://chromewebstore.google.com/detail/%E3%82%88%E3%82%80/bbaickgfdgnecdnkcplaoiopnfghlkna)

Edge asks to allow extensions from other stores: allow it. Opera needs its Install Chrome Extensions add-on first.

## Firefox, desktop and Android {#firefox}

[Add よむ from Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/yomu-reader/)

Works on Android too. Skip the `.xpi` file on GitHub: it isn't signed, so Firefox refuses it.

## Safari, iPhone and iPad {#safari}

1. [Install the free Userscripts app](https://apps.apple.com/app/userscripts/id1463298887) and open it once.
2. In Safari's extension settings, turn Userscripts on and allow it on all websites.
3. [Open yomu.user.js in Safari](https://yomureader.com/yomu.user.js)
4. Open Safari's page menu, choose Userscripts and install the script.

## Any other browser {#userscript}

1. [Install Tampermonkey](https://www.tampermonkey.net/)
2. [Open yomu.user.js](https://yomureader.com/yomu.user.js)

If the file downloads instead, paste its address into Tampermonkey → Utilities → Install from URL.

## Then {#then}

Open a Japanese page and hover a word. Nothing happens? Allow よむ on that site in your browser's extension menu, then reload.
