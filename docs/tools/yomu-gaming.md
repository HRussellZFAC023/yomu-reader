# Yomu Gaming

**Yomu Gaming** is a small desktop app that reads the Japanese in PC games. Press your capture shortcut and it reads the whole screen. If the scene is busy, capture just the part you care about.

## Download

Get the file for your platform from [GitHub Releases](https://github.com/HRussellZFAC023/yomu-reader/releases/latest):

- Linux / Steam Deck desktop mode: `yomu-gaming-<version>-linux-x86_64.AppImage`
- Windows: `yomu-gaming-<version>-win-x64.exe`
- macOS Apple silicon: `yomu-gaming-<version>-mac-arm64.zip`
- macOS Intel: `yomu-gaming-<version>-mac-x64.zip`

On a Steam Deck, use the AppImage in Desktop Mode. Game Mode is not supported yet.

## Setup

1. Install the Yomu Gaming package for your platform.
2. Open Yomu Gaming. The home screen shows the capture shortcut and a **Read my screen** button.
3. Press the shortcut like Print Screen to read the whole screen, or choose **Read part of the screen** for busy scenes. Pick your own shortcut in **Settings**.

Yomu Gaming reads text the same way browser Yomu does, so it works straight away. If you want it to read without a connection, point it at your own reader under **Image text (OCR)**.
