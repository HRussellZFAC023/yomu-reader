# Free Japanese Learning Tools

Yomu turns any page, video, manga or game screen into a Japanese lesson — lookups, readings, and cards you keep.

Pick what you want to read. It works the same way everywhere: press a word, get the answer, keep it if it is worth keeping.

## Take any one of them

You do not have to set all of this up. Install Yomu, start reading web pages, and add the rest when you meet something Yomu cannot read yet.

Kanji works everywhere: press a character inside any lookup to see its [stroke order and readings](/tools/kanji-stroke-order).

## What you need

- A **userscript manager** — Tampermonkey on a computer, Userscripts on iPhone and iPad. Both are free.
- The free [Yomu userscript](https://yomureader.com/yomu.user.js).

That is the whole requirement. [Jiten](https://jiten.moe/), [JPDB](https://jpdb.io), [Anki](https://apps.ankiweb.net/), and your own Yomitan dictionaries all connect if you want them, and none of them are needed to start.

New here? Follow the [install guide](/getting-started).
